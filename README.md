# ren-shi-wu-li-researcher

一个基于“人 / 事 / 物 / 理”框架的深度研究 Skill。

它的目标不是给出短摘要，而是对一个行业、公司、产品、平台、商业模式、社会现象、技术概念或人物做系统性研究，默认联网调研，输出中文长篇研究报告，并在正文中保留来源引用，文末附参考链接。

## 这个 Skill 做什么

- 默认先联网调研，再进入分析
- 用 `人 / 事 / 物 / 理` 作为主体研究框架
- 适合行业、公司、产品、平台、技术、现象、人物等对象
- 输出结构化研究报告，而不是零散信息或短答案
- 支持复杂对象扩展到 `15000-20000` 字级别
- 正文引用来源，文末统一列参考链接

## 适用场景

适合这类请求：

- `研究一下XX`
- `帮我做个深度分析`
- `我想系统搞懂这个领域`
- `给我一份完整研究报告`
- `不要浅层解释，要全面分析`
- `做一个 deep research`

不适合这类请求：

- 只要一句话定义
- 只要新闻快讯
- 只要写作润色
- 只要非常短的结论

## 核心方法

### 人

看清谁在参与、谁掌权、谁受益、谁承担成本、谁是隐形玩家。

### 事

拆解它从开始到结束如何运作，关键节点、价值转移点、信息差和最脆弱环节在哪里。

### 物

识别它依赖的资源、工具、资产、门槛和卡脖子要素。

### 理

追问底层逻辑、本质问题、长期规律、存在原因和未来演化方向。

```text
    ├── SKILL.md
    └── references/

```

## 文件说明

- `SKILL.md`：主 Skill，定义触发条件、研究原则、调研要求、工作流和输出格式
- `references/report-template.md`：完整研究报告模板，约束章节结构和字数层级
- `references/examples.md`：研究摘要和结论口径示例，用来稳定输出风格

## 输出特征

默认报告结构包括：

1. 研究摘要
2. 研究对象定义
3. 人
4. 事
5. 物
6. 理
7. 发展与阶段判断
8. 竞争或关键关系格局
9. 关键案例与证据
10. 核心结论
11. 参考来源

## 安装

将目录放入你的全局 skills 目录，例如：

- Codex: `~/.codex/skills/ren-shi-wu-li-researcher`
- Claude Code: `~/.claude/skills/ren-shi-wu-li-researcher`

重启客户端后生效。

## 定位一句话

这个 Skill 的核心不是“快速知道一点”，而是“用结构化研究把一个陌生对象真正看懂”。
