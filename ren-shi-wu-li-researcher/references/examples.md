# 研究口径示例

以下示例不是完整报告，而是用于稳定“研究摘要 + 结论口径”的参考。

## 示例 1：研究“Claude Code”

### 研究摘要示例

Claude Code 表面上是一款面向开发者的命令行 AI 编码工具，但如果把它放进更大的技术演化脉络里看，它更像是“软件开发代理化”的早期形态。它的关键不在于补全代码，而在于它能读取代码库、运行命令、修改文件、接入外部工具，并在人类审批下完成一段相对完整的工程闭环。围绕它运转的，不只是开发者个人，还有 Anthropic、Node/npm 工具链、企业研发流程、MCP 生态和组织内部的协作方式。本报告最重要的三个判断是：第一，Claude Code 的竞争对象不只是传统 IDE 补全工具，而是整个“手工软件开发工作流”；第二，真正决定它上限的，不只是模型能力，而是它接入环境、理解上下文和执行真实工具的能力；第三，它长期改变的可能不是“程序员是否存在”，而是“程序员的价值重心从执行转向判断、编排与审查”。

### 核心结论示例

- Claude Code 看起来是一个编码工具，本质上是一个运行在终端里的工程执行代理。
- 它最重要的变化不是“写代码更快”，而是“软件开发这件事被重新定义为目标设定 + 代理执行 + 人类审查”。
- 它的长期价值不取决于能补多少代码，而取决于能否接入更多真实环境、外部工具和组织流程。

### 一句话看懂本质示例

- 看懂 Claude Code 的核心一句话：它不是在帮人补代码，而是在把开发工作流从手工流程改造成代理流程。

## 示例 2：研究“直播电商”

### 研究摘要示例

直播电商看起来像一种新的卖货形式，但从人、事、物、理四个维度看，它本质上是流量、供应链与交易闭环高度耦合后的结果。台前最显眼的是主播和内容，真正决定胜负的却往往是平台分发规则、货盘能力、履约能力和投流效率。这个行业之所以高速扩张，不是因为“会说话的人突然变多了”，而是因为短视频流量、支付系统、物流基础设施和消费者决策心理在同一时间成熟了。要理解它，不能只盯着直播间里的话术，而要看到平台、商家、服务商、供应链、投流团队之间的利益关系和权力结构。

### 核心结论示例

- 直播电商表面上是内容生意，本质上是流量和供应链的组织生意。
- 最赚钱的不一定是镜头前的人，而是掌握分发和履约能力的人。
- 普通人若缺乏供应链、流量或复购能力，直接冲进主播角色往往是高风险选择。

### 一句话看懂本质示例

- 看懂直播电商的核心一句话：谁能同时控制流量、货和履约，谁就拿走直播电商的大头利润。
